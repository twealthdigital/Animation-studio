# Architectural Decisions Log

- **AD-001 (Dual-Mode HTML Import)**: Mode A runs inline Three.js character scripts inside a virtual DOM/WebGLRenderer shim to extract live `THREE.Group` hierarchies and `CanvasTexture`s into one master `WebGLRenderer`, avoiding multi-context WebGL exhaustion and guaranteeing clean export. Mode B falls back to a sandboxed `<iframe>` bridge for non-Three.js HTML.
- **AD-002 (Post-Frame Rig Override Pipeline & Additive Rest Pose)**: Procedural HTML characters (`Host_character`, `Globe_character`) animate sub-groups every tick inside `frame(now)`. `HtmlThreeAdapter` and `GltfCharacterAdapter` capture each node's `restRotation` at load, record delta rotations without double-counting rest rotation, and apply bone overrides, procedural motion preset deltas, and solved IK rotations after `frameCallback`.
- **AD-003 (Semantic Node Discovery for Procedural HTML Rigs)**: `HtmlThreeAdapter` walks extracted hierarchies and assigns deterministic node IDs (`node:<path>`) and heuristic humanoid labels (`Head`, `LeftUpperArm`, `LeftForearm`, `RightUpperArm`, `LeftThigh`, etc.) plus descriptions and material names while prioritizing explicit `.name` or `window.STAGECRAFT_SDK.nodes` bindings.
- **AD-004 (Socket-Locked Articulated Pose Mode)**: Double-clicking a character or joint enters Articulated Pose Mode (`StudioEngine.poseModeInstanceId`), locking child bones strictly to local rotation around parent joint pivots and enabling direct pointer drag-to-rotate on limbs so joints never snap off the skeleton.
- **AD-005 (Coalesced Universal Undo/Redo Transactions)**: `StudioWorkspace.commitSceneMutation` records snapshot-based `StudioCommand` entries in `CommandManager` with a 480ms coalesce window per slider/drag key so continuous adjustments produce one clean undo/redo step across every studio tool.
- **AD-006 (World-Transform Preserving Logical Grouping)**: `createLogicalGroup` and `ungroupLogicalGroup` (`src/core/GroupUtils.ts`) compose and invert `THREE.Matrix4` transforms so grouping or ungrouping characters and props keeps their world placement intact while supporting animated `SceneGroupData` parent transforms.
- **AD-007 (Project Schema Migration & Honest Provider Interfaces)**: `migrateProjectData()` (`src/core/migrations.ts`) upgrades earlier IndexedDB projects seamlessly with `groups`, `lockedNodes`, `hiddenNodes`, lighting rigs, multi-camera containers, and `workArea` bounds. External cloud AI/voice providers report honest unconfigured status while local deterministic animation predictions, Tab suggestions, Web Audio mixing, and microphone recording work offline.
- **AD-008 (Software WebGL Pacing & Export Reliability)**: Retains `isSoftwareGl` detection, on-demand `requestRender()`, `afterDraw()` pacing, and synchronous stepped timeline progression during video export with real browser `MediaRecorder` codec checks.
